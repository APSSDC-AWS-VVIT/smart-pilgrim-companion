## 📖 About the Project

Smart Pilgrim Companion is a cloud-based full-stack web application developed under the **APSSDC AWS Cloud & DevOps Internship Program**.

The platform assists pilgrims in planning spiritual journeys by providing temple information, intelligent pilgrimage planning, travel recommendations, estimated budgets, and a seamless cloud-hosted user experience using modern AWS services.

> **Note**
>
> As part of our AWS deployment demonstration, the application was successfully deployed on an **Amazon EC2 instance** with **Amazon RDS MySQL**, **Nginx Reverse Proxy**, and **Gunicorn**.
>
> Since the project currently uses the **default EC2 Public IPv4 address (without an Elastic IP)**, the AWS deployment URL changes whenever the EC2 instance is stopped and started. Therefore, the GitHub Pages deployment remains the permanent public demo, while the AWS deployment is used for cloud deployment demonstration, evaluation, and testing.
